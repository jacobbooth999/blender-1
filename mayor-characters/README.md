# Mayor characters (TikTok "you run the town")
Six mayor options in the bean-head cartoon style (reuses `roman-short/src/videos/rome/toon.ts`), each with 3 reaction poses.
Rebuild: `npx esbuild mayor.ts --bundle --format=iife --outfile=mayor.js && node render.js`

## Chosen mayor: Mayor Mack
The user picked **Mayor Mack** (option 5: The Builder — yellow hard hat, beard, orange jacket, red sash, gold chain).
Whenever the user says "mayor", they mean Mayor Mack (`MAYORS[4]` in mayor.ts).
