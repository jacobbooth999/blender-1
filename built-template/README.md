# built-template: Blender kit for "problem → fix" explainer shorts

This folder builds a vertical comedy-explainer short entirely from one JSON episode file. You get
mannequin-style characters, kit-bash sets, light rigs, paper insert cards, and a 2D layer of
word-by-word captions, colour-coded stickers, speech bubbles and counters. It's all generated by
Python inside Blender 5.x, so episodes are plain text, easy to diff, and re-time automatically
when you swap in a real voice recording.

```
built-template/
  SCRIPT_TEMPLATE.md     how to write an episode (structure, rules, beat → field mapping)
  cast.json              recurring cast: colours, hair, build (edit or add characters)
  episodes/demo_chippy.json   20 s demo using every feature
  blender/
    build.py             entry point: episode JSON → .blend (+ stills / mp4)
    mannequin.py         character builder, pose library, expressions, walk cycle
    sets.py              sets (field, street, room cutaway) and props
    look.py              render presets and light rigs
    inserts.py           paper insert cards that fill in over time
    overlay.py           captions, stickers, bubbles, counters (Video Sequencer)
    timing.py            words.json loading, auto-timing, word anchors
    util.py              materials and primitive meshes
  fonts/                 Poppins ExtraBold (OFL) for captions, Luckiest Guy (Apache 2.0) for stickers
  out/                   build output (git-ignored)
```

## Run it

With a Blender 5.x install:
```bash
blender -b -P blender/build.py -- episodes/demo_chippy.json --stills 1,6.2,13.4
```
Or headless with the `bpy` module (`pip install bpy`, needs Python 3.13):
```bash
python blender/build.py episodes/demo_chippy.json --stills 1,6.2,13.4
```
| Option | Effect |
|---|---|
| *(none)* | build and save `out/<name>.blend`: open it, the `EDIT` scene is the cut |
| `--stills 1.0,4.5` | PNG stills at those episode times → `out/<name>/` |
| `--video` | full render → `out/<name>.mp4` (with the voice if the episode has one) |
| `--engine eevee\|cycles\|workbench` | override the engine (Eevee is the target look) |
| `--scale 0.5` | resolution percentage for fast previews |
| `--samples 16` | render samples |
| `--no-save` | don't write the .blend |

On a headless Linux box Eevee needs EGL (`apt-get install libegl1 libgl1-mesa-dri`). Without a
GPU it's slow, about 13 s per frame at 40% resolution, so use `--engine cycles --samples 10` for
quick previews and render the final with Eevee on a GPU machine.

## How a build is put together
- **One Blender scene per shot**, each with its own set, light rig, cast and camera. Shots never interfere with each other.
- **An `EDIT` scene** strings the shots together in the Video Sequencer and adds the voice and every 2D element on top.
- **Captions** are generated from the word timings, one word at a time at 65% frame height.

## Episode file

```jsonc
{
  "name": "my_episode",
  "fps": 30, "resolution": [1080, 1920], "engine": "EEVEE", "samples": 32,
  "cast": "../cast.json",
  "script": "If you ... you've got ...",     // auto-timed at "wps" words/s when there's no recording
  "voice": "../voice/voice.wav",             // optional; with "words" below
  "words": "../voice/words.json",            // same schema as roman-short/voice/words.json
  "caption_replace": {"pissed": "p*ssed"},   // optional caption censoring
  "shots": [ { ...shot... }, ... ]
}
```

**Time references.** Anything that takes a time accepts:
- seconds: `4.2`
- a word anchor: `{"word": "chippy"}` or `{"word": "But", "nth": 1}` (matching ignores case and punctuation, `nth` counts from 0)
- a word index: `{"word": 12}`
- either anchor with options: `"edge": "end"` and/or `"offset": -0.1`

Anchor everything to words. When the real recording replaces the auto-timing, the whole edit re-times itself. Each build writes the timing it used to `out/<name>.words.auto.json`.

### Shot fields
| Field | Example | Notes |
|---|---|---|
| `start` | `{"word": "But"}` | first shot starts at 0; each shot runs until the next one starts |
| `light` | `"toybox"` | `toybox`, `warm_interior`, `night_exterior`, `paper` |
| `set` | `{"type": "room", "bunting": true}` | `field` (road, trees), `street` (houses, night), `room` (dollhouse cutaway: w, d, h, wall, wall2, floor, window, bunting), `none` |
| `props` | `[{"type": "shed", "at": [0, 2, 0]}]` | tree, table, chair, sofa, counter, rug, pendant (has a real light), toilet, shed, bench, bird, plate |
| `actors` | see below | cast members or seeded extras |
| `crowds` | `[{"n": 40, "area": [-3, 1, 3, 4], "poses": ["cheer", "idle"]}]` | random extras in a rectangle |
| `queues` | `[{"from": [2, 1, 0], "to": [-7, 0, 0], "n": 12, "face": -95}]` | a line of extras |
| `camera` | `{"from": [...], "to": [...], "look": [...], "look_to": [...], "lens": 32, "lens_to": 40, "dof": {"focus": "gaz", "fstop": 2.8}}` | eased glide over the shot; `focus` is a cast name or a point |
| `insert` | see `inserts.py` | replaces set and actors with a paper card; camera is automatic |
| `stickers` | `[{"text": "THE RANGE", "t": {...}, "kind": "win", "dur": 0.6}]` | kinds: `label` yellow, `win` green, `bad` red, `rule` blue, `cta` pink; optional `pos`, `size`, `tilt`, `color` |
| `bubbles` | `[{"text": "OI!", "t": {...}, "pos": [0.36, 0.8]}]` | white rounded box, black text |
| `counters` | `[{"steps": [{"t": .., "text": "QUEUE: 12"}, ...], "until": {...}}]` | value that changes over time |

Overlay positions are normalised `[x, y]` with **y measured from the bottom**. Captions sit at y = 0.35 and stickers default to y = 0.8. Keep bubbles and stickers clear of the caption band.

### Actors
```jsonc
{"who": "gaz",                 // cast key; omit "who" and give "seed" for a random extra
 "at": [x, y, 0], "face": 0,   // degrees; 0 faces the camera side (-Y)
 "pose": "hold", "expr": "happy", "hold": "fish",     // held props: pint, fish, salt, phone
 "look": {"top": "#FF0000"},   // per-shot costume override
 "keys": [{"t": {"word": "chippy"}, "pose": "arms_up", "expr": "shock"}],
 "walk": {"t0": 3.4, "t1": 5.0, "to": [x, y, 0]}}
```
- **Poses** (`mannequin.POSES`): idle, arms_up, cheer, slump, point, wave, shrug, hold, drink, hands_hips, think, sit, walk_a, walk_b. Add your own as a dict of joint angles; the format is documented at the top of `mannequin.py`.
- **Expressions**: neutral, happy, angry, worried, shock, talk.

## Style targets (from the format breakdown)
- **Pace**: 1.7–3 s average shot. Cut on stressed words; stickers land on the noun being named.
- **Inserts**: use paper insert cards for any information that builds up over the episode, and bring the same card back filled in.
- **Ending**: end on the opening composition so the video loops. The demo's last shot glides back to the hook framing.
- **Audio**: voice only, mixed to about −14 LUFS. Captions carry the energy, not music.

## Swapping in a real voice
1. Record the script and make `voice.wav`.
2. Get word timings into `words.json`. The `roman-short/tools/make_voice.py` flow, or any forced aligner, produces this schema.
3. In the episode, remove `"script"` and set `"voice"` and `"words"`. Rebuild. Every word-anchored shot, sticker and pose moves with the new timing.
